# Farmer Procurement IVR — ChatGPT Enhanced Prototype

A realistic keypad-IVR prototype for a Smart India Hackathon style farmer procurement workflow.

## What is improved

- **Three-language opening announcement:** Tamil, English and Hindi are spoken in their own native neural voice before language selection.
- **After language selection, the call stays 100% in that language.** Tamil callers hear only Tamil prompts, Tamil confirmations and Tamil procurement-centre names.
- **Premium neural TTS:** Microsoft Edge Neural voices are generated by the local FastAPI service using `edge-tts`.
- **Browser fallback:** if the neural TTS service cannot be reached, the browser's installed language voice is used.
- **DTMF keypad:** real telephone-style tones for every number, `*`, and `#`.
- **Six-digit Farmer ID:** `#` submits; `*` clears.
- **ID verification and confirmation.**
- **Main IVR menu:** booking, existing booking, live queue, back/end.
- **Booking protection:** an existing active booking is returned instead of silently creating duplicates.
- **Live queue and ETA.**
- **Local demo fallback:** the frontend can still complete the demonstration if FastAPI is temporarily offline.
- **Keyboard support:** `1–9`, `*`, `#`, `C` to call, `Esc` to end.

## Demo flow

1. Press the green call button.
2. The system announces the language choices in Tamil → English → Hindi.
3. Press **1** for Tamil, **2** for English, or **3** for Hindi.
4. Enter a six-digit Farmer ID and press `#`.
5. Confirm the farmer name with `1` or re-enter with `2`.
6. Use the main menu:
   - `1` Book a procurement slot
   - `2` Hear existing booking
   - `3` Hear live queue
   - `9` End / go back

## Run

### Backend

```bash
cd backend
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL, normally `http://localhost:5173`.

## Tamil voice

The frontend calls:

`GET /api/tts?lang=ta-IN&text=...`

The backend uses the Microsoft neural Tamil voice `ta-IN-PallaviNeural`. Internet access is required while generating neural audio. No Tanglish conversion is used.

## Real telephone integration

For an actual phone number, the same state machine can be connected to an Indian telephony provider such as Exotel or Knowlarity. The provider would receive DTMF digits from the caller, call the backend/webhooks, and play generated audio to the phone. The browser keypad is only the demonstration layer; it is intentionally shaped like a real IVR flow so it can be replaced by telephony webhooks later.
